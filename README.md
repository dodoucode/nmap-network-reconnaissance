# nmap-network-reconnaissance
A hands-on Nmap project focused on basic network reconnaissance, open port identification, and service exposure analysis conducted in a controlled lab environment.

# Nmap Network Scanning & Reconnaissance Project

# Overview
This project demonstrates practical, hands-on use of Nmap to perform structured network reconnaissance in a ontrolled and authorized lab environment. The goal was to understand how systems expose services, how different scan techniques affect visibility, and how defenders interpret scan results to assess risk.
he project focuses on discovery, enumeration, and analysis — not exploitation.



# Objectives
- Identify live hosts on a network
- Discover open ports and exposed services
- Perform service and version enumeration
- Understand scan performance tuning and trade-offs
- Observe how packets are generated and transmitted
- Build ethical awareness around network scanning


 Tools Used
- Nmap
- Linux Terminal
- Authorized Local / Lab Network



 Scanning Techniques Performed
Host Discovery
Identified active hosts on the network before scanning ports.

E.g:
nmap -sn <target-ip-range>
